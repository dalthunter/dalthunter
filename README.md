**🔎 Reconnaissance — [TA0043](https://attack.mitre.org/tactics/TA0043/)** → Search websites, social media, employee information, domains, IPs, exposed systems, and other public information.

**🎯 Resource Development — [TA0042](https://attack.mitre.org/tactics/TA0042/)** → Set up domains, servers, malware, accounts, infrastructure, or stolen credentials they will use during the attack.

**🚪 Initial Access — [TA0001](https://attack.mitre.org/tactics/TA0001/)** → Phish an employee, use stolen credentials, exploit a vulnerability, or attack an exposed service such as a VPN.

**🦠 Execution — [TA0002](https://attack.mitre.org/tactics/TA0002/)** → Run malware, PowerShell, scripts, commands, malicious files, or other code on the victim's system.

**📌 Persistence — [TA0003](https://attack.mitre.org/tactics/TA0003/)** → Create another account, install a backdoor, create a scheduled task, or use another method so they can come back later.

**⬆️ Privilege Escalation — [TA0004](https://attack.mitre.org/tactics/TA0004/)** → Start with a normal account and exploit a weakness or steal credentials to become administrator/root.

**🛡️ Defense Evasion — [TA0005](https://attack.mitre.org/tactics/TA0005/)** → Hide files/processes, disable security tools, delete logs, disguise activity, or use legitimate tools to avoid detection.

**🔑 Credential Access — [TA0006](https://attack.mitre.org/tactics/TA0006/)** → Steal passwords, session cookies, authentication tokens, API keys, or other credentials.

**🗺️ Discovery — [TA0007](https://attack.mitre.org/tactics/TA0007/)** → Find computers, servers, users, domain controllers, databases, security software, network information, and valuable files.

**🏃 Lateral Movement — [TA0008](https://attack.mitre.org/tactics/TA0008/)** → Use stolen credentials, RDP, SMB, remote services, or other methods to move from one compromised computer to another.

**📡 Command and Control — [TA0011](https://attack.mitre.org/tactics/TA0011/)** → Make the infected computer communicate with attacker-controlled infrastructure so the attacker can send commands and receive information.

**📂 Collection — [TA0009](https://attack.mitre.org/tactics/TA0009/)** → Gather emails, documents, databases, screenshots, credentials, financial information, or other valuable information.

**🚚 Exfiltration — [TA0010](https://attack.mitre.org/tactics/TA0010/)** → Compress or collect stolen data and transfer it outside the victim's network to attacker-controlled infrastructure.

**💥 Impact — [TA0040](https://attack.mitre.org/tactics/TA0040/)** → Encrypt systems with ransomware, destroy data, steal money, disrupt services, or expose stolen information.
