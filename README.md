<h3>
  🔎 Reconnaissance — <a href="https://attack.mitre.org/tactics/TA0043/">TA0043</a>
</h3>
<p>Search websites, social media, employee information, domains, IPs, exposed systems, and other public information.</p>

<h3>
  🎯 Resource Development — <a href="https://attack.mitre.org/tactics/TA0042/">TA0042</a>
</h3>
<p>Set up domains, servers, malware, accounts, infrastructure, or stolen credentials they will use during the attack.</p>

<h3>
  🚪 Initial Access — <a href="https://attack.mitre.org/tactics/TA0001/">TA0001</a>
</h3>
<p>Phish an employee, use stolen credentials, exploit a vulnerability, or attack an exposed service such as a VPN.</p>

<h3>
  🦠 Execution — <a href="https://attack.mitre.org/tactics/TA0002/">TA0002</a>
</h3>
<p>Run malware, PowerShell, scripts, commands, malicious files, or other code on the victim's system.</p>

<h3>
  📌 Persistence — <a href="https://attack.mitre.org/tactics/TA0003/">TA0003</a>
</h3>
<p>Create another account, install a backdoor, create a scheduled task, or use another method so they can come back later.</p>

<h3>
  ⬆️ Privilege Escalation — <a href="https://attack.mitre.org/tactics/TA0004/">TA0004</a>
</h3>
<p>Start with a normal account and exploit a weakness or steal credentials to become administrator/root.</p>

<h3>
  🛡️ Defense Evasion — <a href="https://attack.mitre.org/tactics/TA0005/">TA0005</a>
</h3>
<p>Hide files/processes, disable security tools, delete logs, disguise activity, or use legitimate tools to avoid detection.</p>

<h3>
  🔑 Credential Access — <a href="https://attack.mitre.org/tactics/TA0006/">TA0006</a>
</h3>
<p>Steal passwords, session cookies, authentication tokens, API keys, or other credentials.</p>

<h3>
  🗺️ Discovery — <a href="https://attack.mitre.org/tactics/TA0007/">TA0007</a>
</h3>
<p>Find computers, servers, users, domain controllers, databases, security software, network information, and valuable files.</p>

<h3>
  🏃 Lateral Movement — <a href="https://attack.mitre.org/tactics/TA0008/">TA0008</a>
</h3>
<p>Use stolen credentials, RDP, SMB, remote services, or other methods to move from one compromised computer to another.</p>

<h3>
  📡 Command and Control — <a href="https://attack.mitre.org/tactics/TA0011/">TA0011</a>
</h3>
<p>Make the infected computer communicate with attacker-controlled infrastructure so the attacker can send commands and receive information.</p>

<h3>
  📂 Collection — <a href="https://attack.mitre.org/tactics/TA0009/">TA0009</a>
</h3>
<p>Gather emails, documents, databases, screenshots, credentials, financial information, or other valuable information.</p>

<h3>
  🚚 Exfiltration — <a href="https://attack.mitre.org/tactics/TA0010/">TA0010</a>
</h3>
<p>Compress or collect stolen data and transfer it outside the victim's network to attacker-controlled infrastructure.</p>

<h3>
  💥 Impact — <a href="https://attack.mitre.org/tactics/TA0040/">TA0040</a>
</h3>
<p>Encrypt systems with ransomware, destroy data, steal money, disrupt services, or expose stolen information.</p>
